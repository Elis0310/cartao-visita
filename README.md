## 📁 Estrutura do Projeto

O projeto foi reestruturado de forma profissional utilizando o terminal Linux:
- `index.html`: Arquivo principal estrutural do site.
- `/css`: Pasta exclusiva para arquivos de estilização (`style.css`).
- `/assets`: Pasta dedicada a imagens, ícones de aba (*favicons*) e documentos adicionais.

## 🚀 Como Executar Localmente

Se quiser rodar o projeto na sua máquina local, abra o terminal e siga os passos:

1. Clone o repositório para o seu computador:
   ```bash
   git clone git@github.com:Elis0310/cartao-visita.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd cartao-visita
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador ou use a extensão *Live Server* no VS Code.
